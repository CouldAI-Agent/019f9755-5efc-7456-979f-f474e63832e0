# Arvagri

Arvagri is a comprehensive B2B2C agricultural marketplace, digital network, and crop health diagnostic ecosystem tailored for Ethiopian farmers and agricultural merchants.

## 🎨 Design System & Color Palette
* **Theme**: Modern, sleek, clean, and accessible UI.
* **Background**: Clean White (#FFFFFF) and Soft Slate Light (#F8F9FA).
* **Primary Accent**: Tech Blue (#0052FF) – primary CTA buttons, Google authentication, navigation.
* **Agricultural Accent**: Leaf Green (#00A859) – agricultural tags, healthy diagnosis states, verification badges.

## 📱 Core Features

### 1. Login & Authentication
* Full Name, Phone Number (pre-filled +251 country code), Email, Password.
* Email/Password authentication & Sign in with Google.

### 2. Home Feed (arva.ke)
* High-performance vertical scrolling video/image feed optimized for low connectivity.
* 24/7 AI Sales Agent matching regional supply with buyer demand.
* Interactive overlay card with direct Chapa Payment checkout trigger.

### 3. Arvagram (Chat Hub)
* Ultra-lightweight, Telegram-inspired messaging interface.
* Direct real-time messaging between buyers, sellers, suppliers, and AI diagnostics.

### 4. Post Creation Page
* Video/photo attachment, Product Title, Detailed Description, Seller Name, Contact Phone, and Location.
* Custom Chapa Paywall logic (Sellers get 3 Free Posts, 4th triggers a fee).

### 5. AI Plant Doctor (Crop Health Diagnostics)
* Camera/Gallery image upload for crop analysis.
* Detects Fungal Infections, Weed Infestations (Arem), and Soil Pests (Tiloch).
* Generates actionable recommendations with Chemical (Common Name) and Trade/Brand Names.

### 6. Offline Messaging Engine & Global Settings
* Offline SMS Queue that syncs unsent messages when connectivity returns.
* Multi-language support (Amharic, Afaan Oromoo, English).
* Official Seller Verification (National Fayda ID and TIN number).

## Setup Instructions
1. Run `flutter pub get` to install dependencies.
2. Run `flutter run` to launch the application.
